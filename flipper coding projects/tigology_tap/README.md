# Tigology Tap

Flipper Zero app (Momentum, API 87.2). Emulates an NTAG215 tag holding one NDEF URI record (`https://tigologyverse.com`), so a phone tapped on the back of the Flipper opens the site. Back exits.

Build: copy this folder into `applications_user/` of the patched Momentum tree and run `./fbt fap_tigology_tap`.
